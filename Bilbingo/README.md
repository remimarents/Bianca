# Bilbingo

Mobiltilpasset bilreise-spill for Barnas Magiske Rom.

## Bruk

Åpne `index.html` direkte i nettleseren, eller publiser hele `Bilbingo`-mappen på GitHub Pages.

1. Velg 2-4 spillere.
2. Velg navn, runder og poengmål.
3. Velg bilfarge og biltype for hver spiller.
4. Trykk på spillerens store knapp når dere ser en bil i riktig farge.
5. Bruk `Angre siste` hvis noen trykker feil.

Spillet lagrer siste spilleroppsett og highscore i `localStorage`.

## Assets

Alle bilder ligger i `assets/`:

- `bilbingo-background.png`
- `color-wheel.png`
- `car-hatchback.png`
- `car-suv.png`
- `car-pickup.png`
- `car-sport.png`

Bilene vises med valgt farge som glød og tydelig fargekort, slik at detaljer som vinduer og hjul fortsatt synes.

## Voksenmodus

Hold tittelen `Bilbingo` inne i 2 sekunder. Da åpnes voksenmodus med poengjustering, nullstill runde og nullstill spill.
